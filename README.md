# Banhammer (Fabric, Minecraft 26.3)

Sla een speler met de Banhammer en hij wordt gebanned (via /ban, dus alleen operators).

Krijg de hamer met:  /give @s banhammer:banhammer
OF
gebruik /adminpannel en gebruik alle functies 

Bouwen:  ./gradlew build   (Java 25 nodig)  -> build/libs/banhammer-1.0.0.jar
